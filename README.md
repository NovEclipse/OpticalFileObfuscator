# OpticalFileObfuscator
A script that makes the file contents of a text file look nearly invisible.
Currently supports  `.txt` files only - I might add more extension support in the future.

# How to use:
1. Download the python file.
2. Make sure the file you want to obfuscate is in the same directory as the python file. `.OOF` file will appear there too.
3. Open and run file in a python IDE.
4. Get the result.
